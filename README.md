# Módulo LMSGI (0373) - Lenguajes de Marcas y Sistemas de Gestión de Información
## Canal: Código Autodidacta

Proyecto centralizado de documentación y código para el ciclo DAM/DAW.
Estructura basada en 70 lecciones atómicas según currículo vigente.

### Stack Tecnológico
- XML, HTML5, CSS3, XPath, XSLT, RSS/Atom, XQuery, Odoo 16.

### Estructura
- UT01: Reconocimiento de lenguajes de marcas
- UT02: Lenguajes de marcas en entornos web
- UT03: Sindicación de contenidos
- UT04: Definición de esquemas y validación XML
- UT05: Conversión y adaptación de documentos XML
- UT06: Almacenamiento de información en XML
- UT07: Sistemas de gestión empresarial (ERP y CRM)
